# Практична робота №8. Безпека застосунку «Кінотека» (варіант 5)

Захищена версія застосунку: перегляд, фільтр за жанром, додавання, редагування, видалення та оцінка фільмів.
Звіт про аудит — у `REPORT.md`.

## Запуск

1. Створити базу: виконати `schema.sql` у MySQL Workbench.
2. У папці проєкту запустити `php -S 127.0.0.1:8000` і відкрити `http://127.0.0.1:8000`.

## Файли

| Файл | Призначення |
|---|---|
| `bootstrap.php` | сесія, обробник помилок, екранування `e()`, CSRF-токен, допоміжні функції |
| `db.php`, `config.example.php` | підключення PDO; пароль лежить поза кодом, у `config.local.php` |
| `movie_functions.php` | перевірка вхідних даних і підготовлені SQL-запити |
| `index.php`, `add.php`, `edit.php`, `_movie_form.php` | сторінки зі списком і формами |
| `delete.php`, `rate.php` | дії, що змінюють дані: лише POST + CSRF-токен |
| `schema.sql` | структура таблиці та індекси |
